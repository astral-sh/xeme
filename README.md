# Oriole

A streaming XML parser in Rust, with an Expat-compatible C interface.

Oriole is under development. It is not yet a production-ready replacement for
Expat. Compatibility with Expat and CPython, resource limits, and reproducible
benchmarks are acceptance criteria for the project.
