# Namespace name reuse study

This original isolated candidate reuses bounded expanded namespace names. Two older-base native cohorts measured about a 4.6% geometric project speedup, and some namespace inputs made fewer allocations. Similar gains without namespaces had no established mechanism; Maven instruction counts increased slightly.

The candidate was rejected after composition onto the current parser. A separate comparison against the same current base without the cache measured a 0.9915× geometric project speedup, with only 7 of 24 conditions improving. The [composition evidence](../namespace-composition/) retains that negative result, the tested source, compatibility checks and actual CPython consumer measurements.

This archive preserves the original positive screens, exact source, allocation and instruction records, focused validation and raw samples. The original 4,065/675 API result belongs to its older source. No namespace cache from this study is retained in the selected runtime. Binary files and Python bytecode are excluded; original recorded hashes remain available.
