# API baseline after rebase — 2026-09-13

The original API baseline describes `fe31da9`. After rebasing the review stack,
we compared main `41bd0cd` with review runtime `55b4b81` using the same pinned
Expat 2.8.4 suite and unchanged candidate resource limits.

Both libraries produced **4,231 passes and 509 failures across all 4,740
configurations**. Every ordered outcome, exit code and normalized assertion
location matched. The reference Expat library passed all 4,740 configurations.
Library origins and the complete test inventory were verified.

The old baseline recognized 387 failures and rejected 122 rows across 11
allocation tests. Four of those rows previously failed at a different assertion;
118 were additional failures. All rejected assertions concern exhausting an
upstream reallocation retry ceiling. The updated baseline records their exact
names, configurations and assertions. Other expectations remain unchanged.

## Separate allocation diagnostic

A diagnostic copy raised only five retry-ceiling constants to 64, retaining the
original tests, parser library and 3-second, 1 GiB address-space and 768 MiB RSS
limits. All 132 configurations of the 11 selected tests then passed. Successful
parsing required these reallocation allowances:

| Tests | Whole input | Incremental input |
| --- | ---: | ---: |
| Seven long-context variants | 8 | 9 |
| Long general-entity name | 12 | 14 |
| Substituted public entity value | 10 | 12 |
| Parameter-entity newline / character extension | 5 | 6 |

Failed attempts reported only `XML_ERROR_NO_MEMORY` or
`XML_ERROR_EXTERNAL_ENTITY_HANDLING`. These diagnostics establish the allocation
schedule difference for these fixtures. The original 509 failures remain in
the baseline.
