## Interpreting the gates

The [detached-frame report](validation/2026-09-10/detached-frames/) covers shared tag grammar ([PR #103](https://github.com/astral-sh/oriole/pull/103)), owned start callbacks ([PR #105](https://github.com/astral-sh/oriole/pull/105)) and owned text callbacks ([PR #106](https://github.com/astral-sh/oriole/pull/106)). The final source passes 392 workspace tests and preserves all 4,740 API outcomes against the preceding source: 4,347 pass and 393 fail. Shared/static CPython retains exactly two known text-grouping failures. Normal native and actual CPython measurements improve every real-project condition against `4b11ace`, while preserving all generated-case regressions and remaining Expat performance gaps. The report explains the exact source/build identities and retains the full original results and independent audits.

Early layers retain CI failures discovered during implementation. Later layers contain their fixes, including selected-allocation behavior on macOS and PBS validator/glibc integration. Historical failure logs and negative experiments remain part of the review history. A passing final head does not mean every intermediate layer passed independently.

Compatibility counts preserve failing assertions. Diagnostic experiments that raise an allocation retry ceiling explain behavior separately; they do not turn the original suite green. Likewise, normalized text callbacks, exact fragmentation, error positions and acceptance are separate contracts. Review the [C interface boundaries](../crates/oriole_expat/) before choosing a consumer.

The full distribution gate is scoped to an opt-in CPython 3.12.13 Linux x86-64 build. Other PBS targets require separate packaging and runtime evidence. The default PBS dependency remains Expat. The [acceptance criteria](../CONTRIBUTING.md#acceptance) remain open for a general production replacement.

The [version-consistent PBS report](validation/2026-09-10/version-consistent-pbs/) preserves a failed full distribution gate on `4b11ace`: the build and validator pass, but two unchanged XML assertions fail. Local follow-up verifies the installed identity and 1,024 threaded parses on glibc 2.17; that gate also fails its XML subcheck. The report explains the earlier local harness's 19 accelerator skips and the distinction between 806 CI executions, 802 PBS methods and the earlier 803 local methods.

The [bounded text-search report](validation/2026-09-10/coalesced-search/) records the following text-scanning optimization, its original-bound API rerun, unchanged strict CPython outcomes, and all native/actual-consumer timings. It preserves the initial relaxed-bound evidence gap and its separate correction.

The [detached-frame ASan campaigns](validation/2026-09-10/detached-frames-fuzz/) add 14.62 million executions on the published `5bc806e` runtime. Independent review verifies fresh instrumented builds, original and evolved corpora, every campaign outcome and archive readback. Leak detection is disabled; subsequent scanner optimizations and PBS distribution builds remain separately scoped.

The [position/string integration report](validation/2026-09-10/scanner-integration/) records the combined source, unchanged original-bound API and strict CPython outcomes, 395 workspace tests plus one doc test, and all matched native/consumer samples. Isolated studies, generated regressions, the unselected name-scan experiment and a corrected postprocessing assumption remain separately visible.

The [closing-tag integration report](validation/2026-09-10/end-tag-integration/) records validated-name reuse, 397 workspace tests plus one doc test, unchanged original API and strict CPython outcomes, and additional End-handler lifecycle and allocation probes. Every native and actual-consumer condition improves against the preceding runtime; isolated regressions remain recorded.
