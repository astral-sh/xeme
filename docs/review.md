# Reviewing Oriole

The [SIMD Text lane-mask report](validation/2026-09-12/text-lane-masks/) records selected source `cacc0b1b` and two separate normal-build measurement epochs. A 16-byte mask locates the first delimiter or uncertain byte while an LF mask counts newlines only in the preceding text. Short tails, the 64 KiB boundary, previous-CR handling, raw ownership and position publication retain their existing paths. The first fixed16 classifier was rejected with effectively flat native time and generated regressions; no downstream Python/API/strict runs were performed for it. The LF follow-up has its own source, build, codegen, full compatibility gates and confirmation.

LF confirmation observes 1.55% less native real-input time and 1.21% less CPython time against namespace storage, remaining 1.4248× and 1.1745× Expat. Native improves in 22/24 real conditions and CPython in 23/24; four CPython conditions meet the roughly 1.10× target. All 132 condition rows and 29 adverse rows across the five campaigns remain separate, including all four LF confirmation regressions. Shared-host counters and affinity do not establish isolation or statistical significance. All 455 Rust tests, formatting, strict workspace/benchmark Clippy and six C consumers pass; original API/strict outcomes remain unchanged, including known failures. Two supplemental semantic tests pass per linkage. Dependency review retains three checksum-pinned archives and 156 source files with licenses. The original successful correctness binding and the later descriptive-label correction/rebinding remain explicit; the nine execution/read scripts were unchanged, and no target failure or rerun resulted. Current-source sustained fuzzing, installed PBS and cross-platform dependency execution are not inferred.

The implementation is published in native GitHub Stack 3, starting at [PR #1](https://github.com/astral-sh/oriole/pull/1), and continues in Stack 104 from [PR #102](https://github.com/astral-sh/oriole/pull/102). Each layer uses the preceding layer as its base, keeping implementation changes and their evidence reviewable together.
